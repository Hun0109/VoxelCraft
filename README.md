# 🌍 VoxelCraft 3D (복셀크래프트) - 웹 3D 멀티플레이 샌드박스

> 웹 브라우저에서 초대 링크 하나로 최대 여러 명이 함께 즐기는 **3D 마인크래프트 스타일 복셀 샌드박스 게임**!  
> 별도의 백엔드 서버나 설치 없이 **Three.js (WebGL)** 와 **WebRTC (PeerJS)** P2P 기술을 활용하여 친구들과 무료로 함께 블록을 캐고 건물을 지을 수 있습니다.

---

## 🎮 게임 특징

1. **🧱 3D 복셀 월드 & 블록 설치/파괴**
   - 언덕, 지하 광물, 나무가 자동으로 생성되는 절차적 지형
   - **좌클릭**: 블록 파괴 (소리와 함께 블록 제거)
   - **우클릭**: 블록 설치 (선택한 블록 놓기)
   - 8가지 블록: 잔디, 흙, 돌, 통나무, 나뭇잎, 벽돌, 다이아몬드, 유리

2. **👥 실시간 3D 멀티플레이어 (WebRTC P2P)**
   - 방장(Host)이 월드를 열고 링크나 코드를 공유하면 친구가 같은 3D 월드에 즉시 입장!
   - 다른 플레이어들의 3D 복셀 아바타와 닉네임이 실시간으로 렌더링되며, 걷고 점프하고 블록을 짓는 모습이 실시간 동기화됩니다.
   - [T] 또는 [Enter] 키로 실시간 채팅 지원

3. **🎨 심플 & 모던 다크 UI**
   - 불필요한 장식을 배제한 세련된 미니멀 다크 HUD
   - 중앙 조준선 (`+`) 및 하단 핫바 (숫자키 1~8)

---

## 🕹️ 조작 방법

- **이동**: `W`, `A`, `S`, `D`
- **점프**: `Spacebar`
- **달리기**: `Shift`
- **시점 회전**: 마우스 이동 (화면 클릭 시 마우스 고정, `ESC`로 해제)
- **블록 파괴**: 마우스 좌클릭
- **블록 설치**: 마우스 우클릭
- **블록 선택**: 숫자키 `1` ~ `8` 또는 마우스 휠
- **채팅**: `Enter` 또는 `T`
