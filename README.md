# 💥 BOOM ARENA (붐 아레나) - 4인 실시간 파티 배틀

> 웹 브라우저에서 초대 링크 하나로 최대 4명이 함께 즐기는 실시간 파티 액션 게임!  
> 별도의 백엔드 서버 없이 **WebRTC(PeerJS)** P2P 기술을 활용하여 친구들과 무료로 초저지연 플레이가 가능합니다.

---

## 🎮 게임 특징 및 모드

1. **💣 폭탄 돌리기 (Bomb Tag)**
   - 라운드가 시작되면 4명 중 1명에게 랜덤으로 시한폭탄이 부착됩니다.
   - 폭탄을 가진 채로 타이머가 0이 되면 **쾅! 탈락!**
   - 상대를 쫓아가 몸을 부딪히거나 대시하여 폭탄을 다른 사람에게 넘기세요.
   - 끝까지 살아남은 최후의 1인이 승리!

2. **🥊 링아웃 난투 (Brawl Arena)**
   - 경기장 주변의 붉은 위험 지대(자기장)가 점점 줄어듭니다.
   - **Spacebar(대시)** 와 파워업 아이템(속도 번개 ⚡, 메가 펀치 🥊, 배리어 쉴드 🛡️)을 활용해 상대를 장외로 밀쳐내세요!

3. **🤖 솔로 연습 & AI 봇**
   - 친구가 없거나 혼자 심심할 때도 문제없습니다!
   - [혼자 연습]을 누르면 스마트한 AI 봇 3명이 자동으로 채워져 바로 게임을 시작할 수 있습니다.

4. **👤 로그인 / 회원가입 & 캐릭터 옷장**
   - 브라우저 로컬 저장소 기반 회원가입/로그인 및 게스트 즉시 접속 지원
   - 네온 컬러(6종)와 모자/악세사리(왕관, 선글라스, 천사링, 악마뿔, 고양이귀 등) 커스터마이징
   - 전적(승률, 승수) 및 코인 자동 저장

---

## 🕹️ 조작 방법

- **이동**: `W`, `A`, `S`, `D` 또는 `방향키 (↑, ↓, ←, →)`
- **대시 / 밀치기**: `Spacebar` (스페이스바)
- **감정 표현 (이모지)**: 숫자키 `1` (😂), `2` (💣), `3` (🔥), `4` (👑)
- **모바일 지원**: 스마트폰 터치 가상 조이스틱 & 대시 버튼 지원

## 🚀 로컬 실행 방법

브라우저에서 `index.html`을 바로 더블클릭하여 열거나, 로컬 웹서버를 실행합니다:

```bash
# Python 내장 서버로 실행 (추천)
py -m http.server 8080
```
브라우저에서 `http://localhost:8080` 접속!

## 🌐 GitHub Pages 무료 배포 (친구와 플레이하는 방법)

1. GitHub에서 새 레포지토리(Repository) 생성 (예: `boom-arena`)
2. 터미널에서 저장소 연결 후 푸시:
   ```bash
   git remote add origin https://github.com/<본인-아이디>/<레포지토리-이름>.git
   git branch -M main
   git push -u origin main
   ```
3. GitHub 저장소의 **Settings** -> **Pages** 메뉴 진입
4. **Source**: `Deploy from a branch` 선택, Branch를 `main` / `/(root)`로 지정 후 **Save**
5. 1~2분 뒤 생성되는 웹 주소(예: `https://<아이디>.github.io/<레포지토리-이름>/`)로 접속!
6. 방을 만든 뒤 **[초대 링크 복사]** 버튼을 눌러 카카오톡이나 디스코드에 링크를 보내면 친구들이 바로 들어옵니다!
